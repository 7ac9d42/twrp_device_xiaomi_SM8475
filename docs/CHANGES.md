# 改动说明

## 设备适配

- 配置 liuqin 的显示、触控、亮度、USB、A/B 和动态分区。
- 生成 header v4、无内核的独立 Recovery 镜像。
- 按归档固件设置产品首发 API 33、board 首发 API 31，并检查最终镜像属性。
- 集成 Qualcomm Keymaster、KeyMint、Gatekeeper、QSEE 和 boot control 服务。
- 配置 FBE v2、wrapped key 与 metadata 加密，启用 vendor.gatekeeper.disable_spu。
- 保留中文界面、ADB、MTP、fastbootd 和日志功能。

## 功能修复

- 使用上游动态属性覆盖入口读取已安装 system 的 release、安全补丁及 vendor 安全补丁，撤销固定版本日期；安全服务等待上游 storage 就绪通知，避免提前缓存旧值。
- 修正锁定上游动态属性名单的二次字符串化，直接消费构建生成的 C 字符串；不修改动态读取流程。
- 沿用上游在临时厂商分区卸载后发布模块就绪通知的顺序，不再保留本地 module-order 补丁。
- 为 boot control 添加 /misc 分区配置。
- 补全两种触控面板的固件提取清单。
- 按目标固件设置 RPMB 节点的所有者和访问权限。
- 配置 DSP 固件搜索路径、只读挂载标签与电池服务启动顺序。
- 使用 libvndksupport 和 libcgrouprc 的真实运行库，配置厂商链接命名空间。
- 修正 GPT 库对短读写、EINTR 和零进展的处理；在头/数组 CRC、分配和遍历前检查元数据及磁盘范围，保留合法布局和主备快照语义。
- 移除 USB 配置中没有消费者的两条 g2 目录创建，不改变 g1 功能。

## 构建与工具

- 保留上游构建版本和 SDK，运行时仅覆盖解密所需的真实系统属性；删除随固定版本覆盖引入的 CTS 版本列表补丁。
- 集成 crash_dump64 原生崩溃日志工具。
- 固定经核对的 YARP 官方依赖及 LVGL/GUI2 资源，使用上游已修复的模块加载通知顺序；更新策略见 UPSTREAM。
- 提供标准 Ubuntu 24.04 hosted runner 的手动 CI，限制并发和内存目标，检查磁盘余量并设置阶段超时。
- 从已测镜像按完整 SHA-256 恢复厂商载荷，保留原始固件提取方式。
- 固定 repo v2.71，同步网络默认 16 并发、checkout 默认 4 并发，取消独立串行 clang checkout；Soong 前端为 4 并发、最终 Ninja 后端为 6 并发，保留 6 GiB Soong Go 内存目标和约 8 GiB swap。
- clang 使用显式根目录选集，Rust 排除其他宿主平台和旧 Linux 工具链版本；同步前核对选集覆盖上游声明的工具链版本。
- 在源码同步前恢复跨运行 ccache，上限 5 GiB，位于沙箱可写的 `out/ccache`；保留同平台内容校验回退，并区分历史缓存恢复和本轮内部命中。
- 单独缓存精确提交的 clang Git 对象库，上限 3 GiB；不整体缓存源码、`.repo` 或构建输出。恢复失败或未命中时隔离不完整对象库，避免阻塞冷同步。
- 同一提交的 CI #7/#8 均通过镜像验证：同步步骤 11:45 / 9:40，编译 26:57 / 18:15，runner 总时长 42:29 / 30:50；跨运行 ccache 恢复成功，可缓存调用命中率 99.98% / 100%。详细基线及验证边界见 README。
- 同步和编译日志实时显示，提供 30 秒资源心跳、阶段计时和 Actions 性能汇总。
- 添加镜像格式、依赖库、服务配置、GUI2 字体、VINTF 与 AVB 哈希检查。
- 镜像提取复用跨平台相对路径检查；启动配置按 service 段验证，ELF 校验仅使用可对外解析的导出符号。
- ERoFS 主机读取工具按上游源码提交隔离缓存，避免更新锁定版本后复用旧库。
- 添加合成内存 I/O 的 GPT 回归，覆盖有效布局、损坏元数据、短 I/O 和提交前检查，使用 ASan/UBSan，不访问真实块设备；CI 在下载载荷和同步源码前执行。本地通过不代替 Android CI 或真机验收。
- 同步 #8 的实际解密和触控验证边界；基于既有诊断拆分前后端并发：保留单次 `m -j4`，通过 `BACKEND_JOBS=6` 和锁定 Soong 的 `NINJA_EXTRA_ARGS` 只提高最终 Ninja 并发，同步和内存参数不变。
